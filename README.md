# 🌍 Travel Website

A modern and responsive **Travel Website** designed to make exploring destinations more engaging and convenient. The project focuses on an attractive user interface, organized layouts, and a smooth browsing experience for users interested in discovering travel destinations.

## ✨ Features

* 🌎 **Explore Destinations** – Discover travel destinations through an engaging interface.
* 🎨 **Modern UI/UX** – Clean layout with visually appealing design elements.
* 📱 **Responsive Design** – Designed to provide a consistent experience across different screen sizes.
* 🧩 **Reusable Components** – Modular components for organized and maintainable code.
* ⚡ **Next.js Framework** – Built with a modern React-based framework.
* 🗂️ **Structured Codebase** – Organized application, components, utilities, and styling.

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Library:** React
* **Language:** TypeScript / JavaScript
* **Styling:** CSS and project-specific styling
* **Package Management:** npm / pnpm

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm or pnpm
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Poorani-S/Travel-Website.git
```

**2. Navigate to the project directory**

```bash
cd Travel-Website
```

**3. Install dependencies**

Using npm:

```bash
npm install
```

Or using pnpm:

```bash
pnpm install
```

**4. Start the development server**

Using npm:

```bash
npm run dev
```

Or using pnpm:

```bash
pnpm dev
```

**5. Open the application**

Visit http://localhost:3000 in your browser.
